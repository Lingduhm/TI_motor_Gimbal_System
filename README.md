## 项目概述

系统由三个硬件单元组成，协同完成竞赛任务：

| 单元 | 主控 | 职责 |
|------|------|------|
| 循迹小车 | MSPM0G3507 (TI DriverLib) | 黑线循迹、多圈任务管理、圈数计数 |
| 云台控制器 | STM32F103C8T6 (HAL) | 接收视觉坐标、驱动双轴舵机对准目标 |
| 视觉模块 | OpenMV (MicroPython) | 目标识别、坐标计算、串口上报 |

**任务流程**：按键选择圈数 → 小车循线行驶并计转弯圈数 → 任务完成后 LED 闪烁指示；与此同时，云台持续追踪/扫描目标，对准后 PB12 触发信号置高。

## 硬件组成

### 循迹小车（MSPM0G3507）

- 主控：TI MSPM0G3507（32MHz Cortex-M0+）
- 电机驱动：2 路 H 桥，驱动 A/B 两轮
- 传感器：5 路灰度红外传感器（L2、L1、M0、R1、R2），下拉输入，黑线为低电平
- 按键：5 个独立按键（KEY1–KEY5），上拉输入
- 指示灯：LED1（GPIOB PIN_22）

### 云台控制器（STM32F103C8T6）

- 主控：STM32F103C8T6（72MHz Cortex-M3，HSE 8MHz + PLL ×9）
- 舵机：2 路 PWM 舵机（X 轴水平、Y 轴俯仰），TIM2 CH2/CH3
- 通信：USART1 接收 OpenMV 坐标数据（115200 baud）
- 按键：KEY1（PA12）、KEY2（PB3），上拉输入
- 输出：PB12 触发电平（对准成功置高）
- I2C：SCL（PB6）、SDA（PB7），预留扩展

### 视觉模块（OpenMV）

- 摄像头：QVGA 分辨率（320×240），灰度模式
- 通信：UART3，115200 baud，自定义帧协议
- 目标类型：十字靶标（低密度、低凸度黑色色块）

## 软件架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    OpenMV 视觉模块                               │
│  摄像头采集 → 色块检测 → 主次轴交点计算 → UART3 发送坐标        │
└────────────────────────┬────────────────────────────────────────┘
                         │ UART 115200 baud  帧协议
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                 STM32F103 云台控制器                              │
│  USART1 中断接收 → 帧状态机解析 → X/Y 轴 PID → TIM2 舵机 PWM         │
│  按键 → flag 模式切换（追踪 / 扫描）                                 │
│  PB12 触发输出（对准成功）                                      │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                 MSPM0G3507 循迹小车                              │
│  TIMA0 5ms ISR → TaskManager → 任务状态机（IDLE/RUN/DONE）     │
│  sensor_read → 增量式 PID → Motor A/B 差速驱动                 │
│  转弯状态机：刹车 → 原地旋转 → 停稳复位 → 圈数计数             │
└─────────────────────────────────────────────────────────────────┘
```

## 子系统说明

### MSPM0G3507 循迹小车

#### 文件结构

| 文件 | 说明 |
|------|------|
| `empty.c` | 主程序入口，中断服务函数（TIMA0、UART0） |
| `task.c / task.h` | 任务管理器，状态机调度，按键去抖 |
| `sensor_rebuild_02.c / sensor.h` | 传感器读取、循迹 PID、转弯状态机 |
| `motor.c / motor.h` | 电机 PWM 封装（A/B 两轮正反转、停止） |
| `key.c / key.h` | 5 路按键读取 |
| `ti_msp_dl_config.c / .h` | SysConfig 生成的外设初始化（TIM、UART、GPIO、SPI） |

#### 任务状态机（task.c）

```
IDLE  ──[按键1-5]──►  RUNNING  ──[转弯计数到达目标]──►  COMPLETED
  ▲                                                           │
  └───────────────[1.5s 自动复位]─────────────────────────────┘
```

- **IDLE**：等待按键，电机停止
- **RUNNING**：执行循迹 PID，监听 `turn_completed_flag`，累计转弯次数
- **COMPLETED**：停车，LED 闪烁，1.5 s 后自动复位

圈数与目标转弯次数对应关系：

| 按键 | 圈数 | 目标转弯次数 |
|------|------|------------|
| KEY1 | 1 圈 | 5 次 |
| KEY2 | 2 圈 | 9 次 |
| KEY3 | 3 圈 | 13 次 |
| KEY4 | 4 圈 | 17 次 |
| KEY5 | 5 圈 | 21 次 |

#### 循迹与转弯状态机（sensor_rebuild_02.c）

**主状态**：`STATE_STRAIGHT`（直线）/ `STATE_TURN_LEFT`（左转）

**转弯子状态**：

```
PHASE_ENTER_BRAKE  →  PHASE_SPINNING  →  PHASE_EXIT_BRAKE
  （15 周期刹车）      （原地左转，          （15 周期停稳，
                       M0 检测智能退出         置 turn_completed_flag）
                       或 1000 周期超时）
```

转弯触发条件：`L2 传感器检测到黑线 && 直线状态 && 冷却计数为 0`

**传感器偏差编码**（L1、M0、R1 三路）：

| L1 M0 R1 | 偏差值 | 含义 |
|-----------|-------|------|
| 0 1 0 | 0 | 居中 |
| 1 1 0 | −10 | 轻微偏右 |
| 0 1 1 | +10 | 轻微偏左 |
| 1 0 0 | −30 | 明显偏右 |
| 0 0 1 | +30 | 明显偏左 |
| 0 0 0 | ±50 | 丢线，按上次方向强制纠偏 |

### STM32F103 云台控制器

#### 文件结构

| 文件 | 说明 |
|------|------|
| `main.c` | 主循环，按键读取，模式切换，误差判断触发 |
| `pid.c / pid.h` | X/Y 轴 PID 控制器 |
| `chuanko.c / chuanko.h` | UART 帧接收状态机，坐标解析 |
| `Servo.c / Servo.h` | 舵机角度封装，CCR 读写 |
| `PWM.c` | TIM2 CCR 直接写入封装 |
| `tim.c` | TIM2 PWM 初始化（20ms 周期，500–2500 μs） |
| `usart.c` | USART1 初始化（115200 baud，接收中断） |
| `gpio.c` | GPIO 初始化 |

#### 工作模式

| 模式 | 触发按键 | 行为 |
|------|---------|------|
| **flag=1 追踪** | KEY1（PA12） | OpenMV 发来坐标后直接执行 X 轴 PID 对准 |
| **flag=2 扫描** | KEY2（PB3） | TIM2 CCR2 从 2350 逐步递减（慢速俯仰下压），发现目标后锁定位置，再执行 PID 对准 |

对准判断：`|xxx - x_center| < 4`（追踪）或 `< 5.0`（扫描）时 PB12 置高。

#### UART 帧协议（chuanko.c）

```
┌───────┬────────┬────────┬────────┬────────┬───────┐
│ 0x2C  │ X_高字节│ X_低字节│ Y_高字节│ Y_低字节│ 0x5B  │
│ 帧头  │        │        │        │        │ 帧尾  │
└───────┴────────┴────────┴────────┴────────┴───────┘
```

坐标还原：`xxx = ((X_高 << 8) | X_低) / 100.0f`，单位为像素（浮点）。

### OpenMV 视觉模块

#### 文件

| 文件 | 说明 |
|------|------|
| `openmv_8_19_10.py` | 完整视觉处理脚本 |

#### 处理流程

1. 捕获灰度帧（QVGA 320×240）
2. 在阈值 `(0, 90)` 内查找黑色色块
3. 多级过滤：`density < 0.35`、`solidity < 0.65`、`convexity < 0.7`、`area` 在 50–20000 之间
4. 选取密度最低的色块（最接近十字形）
5. 计算主轴与次轴的交点坐标（`intersection()`）
6. 有效性验证：`length_ratio > 0.55` 且 Y 坐标在 50–190 之间
7. 坐标放大 100 倍后打包为 6 字节帧发送

## 关键算法

### 增量式 PID（循迹）

```
Δu(k) = Kp·[e(k)−e(k−1)] + Ki·e(k) + Kd·[e(k)−2e(k−1)+e(k−2)]
u(k)  = u(k−1) + Δu(k)
```

特性：
- 积分分离：`|e| ≥ 12` 时关闭积分，避免大偏差超调
- 微分一阶低通滤波（α = 0.7），抑制传感器噪声
- 增量限幅 `±3`，输出总限幅 `±15`（正常）/ `±25`（丢线）
- 死区 `|e| ≤ 4` 时不纠偏，抑制蛇形抖动

### X 轴 PID（云台追踪，pid.c）

- 带前馈控制：`feedforward = target_velocity × feedforward_gain`
- 带动态积分：误差 > 20 时可扩大积分增益（当前配置为 1×）
- 死区 `|e| < 1.2` 时清零误差，积分缓慢衰减（× 0.7）
- 输出限幅：CCR 值限制在 500–2500

## 操作说明

### 循迹小车启动

1. 上电后系统进入 `IDLE` 状态，电机停止。
2. 按下 KEY1–KEY5 选择目标圈数（1–5 圈）。
3. 小车自动开始循线行驶，每完成一次转弯计数一次。
4. 达到目标圈数后停车，LED1 开始闪烁（约 1.5 s 后自动复位到 IDLE）。

### 云台视觉启动

1. **追踪模式（KEY1）**：按下 KEY1，OpenMV 检测到目标后 STM32 执行 X 轴 PID 对准，误差 < 4 像素时 PB12 置高。
2. **扫描模式（KEY2）**：按下 KEY2，云台从高位（CCR2=2350）缓慢下压扫描，检测到目标后停止下降并锁定，随后执行 PID 对准，误差 < 5 像素时 PB12 置高。
